# 使用说明

### 1. 代理连接信息
安装完成后，您可以使用以下信息连接 SOCKS5 代理：
- **服务器 IP**: 您的服务器公网 IP
- **端口**: `${PANEL_APP_PORT_HTTP}` (默认 2020)
- **类型**: SOCKS5
- **认证**: 需要用户名和密码

### 2. 用户管理
- **用户名**: 您在安装时设置的 `${USERNAME}`
- **密码**: 您在安装时设置的 `${PASSWORD}`

### 3. 安全建议
- 请务必修改默认的用户名和密码。
- 如果您的服务器有防火墙（如 1Panel 面板自带的防火墙、云服务商的安全组），请确保放行了 TCP 端口 `${PANEL_APP_PORT_HTTP}`。

### 4. 进阶配置
本镜像支持通过环境变量 `USER` 配置多个用户，格式为 `user1:pass1,user2:pass2`。
