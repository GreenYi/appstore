# 使用说明
# 关于 ESPHome
bili-sync 是一款专为 NAS 用户编写的哔哩哔哩同步工具。

它的基本的工作原理是使用用户填写的凭据定期扫描视频合集、收藏夹等，获取到本地未下载过的内容并保存到本地，维持本地视频库与哔哩哔哩网站的同步。

下载的内容包括视频、封面、弹幕、标签与简介信息等，这些文件整体保持与 Emby、Jellyfin 等媒体服务器软件兼容的文件布局，使得目的文件夹可以直接被作为媒体库添加到这些软件中，无需干预自动识别。

### 1. 首次运行与登录
安装完成后，请立即查看容器日志（在 1Panel 容器详情 - 日志中查看）。
在日志中寻找如下内容：
```text
WARN 生成 auth_token：xxxxxxxxxxxxxx，可使用该 token 登录 web UI
```
复制该 Token，访问 `http://IP:12345`，在设置页面输入并认证。

### 2. 路径配置
- **配置文件**：存储在您设置的“配置文件夹路径”中。
- **视频下载**：在 Web UI 的设置中，请将下载目录指向 `/downloads`（即您在安装时映射的下载路径）。

### 3. 媒体库集成
如果您使用 Emby 或 Jellyfin，可以将本应用的下载目录添加为媒体库。
- 若需同步 UP 主头像，请在 Web UI 中配置“UP 主头像保存路径”，并确保该路径在 Docker 卷中正确映射。
